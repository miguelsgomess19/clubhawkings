# 🎬 Club Hawkings
### Uma loja. Dois mundos.

## 📌 Sobre o projeto

O **Club Hawkings** é um projeto de site inspirado na série *Stranger Things*, desenvolvido com o objetivo de criar uma loja temática com uma identidade visual própria, reunindo referências ao universo da série em uma experiência de navegação simples e organizada.

O projeto faz parte de um trabalho de desenvolvimento web e busca colocar em prática conhecimentos de programação, estilização e organização de arquivos.

## 🚀 Funcionalidades

- Página inicial com a identidade visual da loja.
- Sistema de cadastro e login de usuários.
- Navegação entre as páginas do site.
- Área de produtos relacionados ao tema Stranger Things.
- Formulários para envio de informações.
- Interface personalizada com cores e elementos inspirados na série.

*As funcionalidades disponíveis dependem da implementação atual do projeto.*

## 🛠️ Tecnologias utilizadas

- **HTML5:** estrutura das páginas.
- **CSS3:** estilização e aparência do site.
- **PHP:** processamento das páginas e funcionalidades.
- **MySQL:** banco de dados, caso utilizado na configuração do projeto.
- **Git e GitHub:** controle de versão e armazenamento do código.
- **Visual Studio Code:** ambiente de desenvolvimento.

## 💻 Como executar o projeto

### 1. Baixe o projeto

Clone o repositório do GitHub dentro da pasta `Documentos`:

```bash
git clone https://github.com/miguelsgomess19/clubhawkings-.git clubhawkings
```

### 2. Abra o projeto no Visual Studio Code

No terminal, execute:

```powershell
cd "$HOME\Documents\clubhawkings"
code .
```

### 3. Inicie o servidor PHP

No terminal do VS Code, execute:

```powershell
cd "$HOME\Documents"
php -S localhost:8000
```

**Importante:** o servidor deve ser iniciado na pasta `Documentos`, que contém a pasta `clubhawkings`.

### 4. Acesse o site

Abra o navegador e entre no endereço:

http://localhost:8000/clubhawkings/

Se o arquivo `index.php` estiver na raiz da pasta do projeto, o site será carregado por esse endereço.

### ⚠️ Requisitos

- PHP instalado e disponível no terminal.
- Navegador atualizado.
- Visual Studio Code recomendado para visualizar e editar os arquivos.
- Banco de dados configurado, caso o sistema utilize MySQL.

O objetivo do projeto é desenvolver uma loja temática aplicando conhecimentos de desenvolvimento web, organização de arquivos, criação de interfaces e programação com PHP.
